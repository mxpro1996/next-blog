**当年这个游戏只能不完美结局，不知道是多少人的意难平。** \
**本文针对天降少女2在镜之湖黑屏，不能打出完美结局的问题。** 

## 问题表现
&nbsp;&nbsp;按照理想的完美结局设计流程，主角应该集齐10个碎片后，能够进入**镜之湖**这个重要剧情点，但是全网的帖子上面看到的大多都是：费尽心机集齐碎片，但是在镜之湖三层进入传送门后，会回到大地图再次重复“镜之湖”开放的剧情，并且伴随**黑屏**。\
&nbsp;&nbsp;有大牛可能要说了，**黑屏又不是不能玩**（按下左/右软键，仍然可以暂时看到游戏画面）。但是就算顶着黑屏，打完最终BOSS，也不能按预料之中触发完美结局。

## 原理分析
&nbsp;&nbsp;从何谈起呢，jadx盘古开天吗？总之喜闻乐见的J2ME时代，就没有几个国产java游戏不用proguard混淆代码的，所以本次修复看了好几年的天书，就像是下面这种：
```a(int) a(int,int) a(int,int,int)```\
&nbsp;&nbsp;做过逆向解混淆的，应该知道我在吐槽什么。我只能被迫jadx+kemulator做了好久的黑盒测试，直接针对引擎进行功能分析了。（此处感谢RPGMaker，让我能够类比rpg的原理）\
&nbsp;&nbsp;废话不多说，我们开始抽丝剥茧：RPG游戏基本上是事件驱动，所以我们的重点关照对象是jar包里面的"script.pak"。

## 附录：魔法吟唱
&nbsp;&nbsp;虽然并不一定需要，但还是顺带放点这游戏的金手指。有没有想起Rivio的**漆黑惊栗**，当年有游戏会在结局把作弊码交给玩家。不过天降系列并不是这种情况，**这个作弊码都是逆向发掘的产物**。
> **前置条件**：在游戏内任何时候，先**按住 `*` 键的同时按下 `#` 键**，此时后台会切换到“作弊打开”状态。接着依次按下后面的数字序列即可。\


| 序号 | 功能 | 按键序列 |
| --- | --- | --- |
| **【0】** | 全员属性/技能拉满 | `#` `1` `1` |
| **【1】** | 全员满血/满蓝恢复 | `*` `1` `1` |
| **【2】** | 获得全部核心装备/道具 | `#` `1` `2` |
| **【3】** | 技能点/天赋点全满 | `#` `1` `3` |
| **【4】** | 角色进入无敌/隐身状态 | `*` `2` `1` |
| **【5】** | 升级 | `5` |
| **【6】** | 瞬间关卡胜利 / 时间清零 | `#` `9` `9` |
| **【7】** | 暴富（直接获得 10W 金币/经验） | `#` `1` `4` |
| **【8】** | 状态重置（恢复初始面板） | `*` `2` `2` |
